# Figura SVG Studio

面向论文插图的本地 SVG 编辑器。提供动态欢迎页、独立历史项目、可编辑矢量重绘、图层与属性面板，以及始终可用的 AI 修改输入框。

## 运行

需要 Node.js 22.13 或更新版本（PDF 解析依赖）。

```powershell
npm install
npm start
```

打开 http://127.0.0.1:4317。也可以在安装依赖后双击 `start.cmd`。设置 `PORT` 可更换端口。

## 编辑

- 启动和刷新先进入欢迎页。主视觉包含 SVG 线条绘制、节点浮现与轻微悬浮；项目卡片、弹窗、页面切换及附件均有过渡动效。页面隐藏时暂停循环动画。
- 欢迎页和顶栏「新建」提供「从 PNG 新建」「建立空白项目」。空白项目设置名称、保存文件夹、尺寸和背景后，在所选位置创建 SVG，并自动保存浏览器草稿，默认选中内容图层，可直接用 AI 绘制。
- 历史项目显示缩略图和最后编辑时间，点击后打开。原有单份浏览器草稿会迁移为一个项目；迁移成功前保留旧数据。
- 「保存」或 `Ctrl+S` 写回已关联的磁盘文件；「另存为」或 `Ctrl+Shift+S` 更换位置和名称。文件夹支持手动输入绝对路径，或在「浏览」中进入子目录、返回上一级。
- 新建和另存为不会覆盖同名文件。保存会检查磁盘版本；如果文件被外部程序修改，会保留外部内容并提示另存为。
- 欢迎页或「新建」中的「从 PNG 新建」：先确认原图、共享重绘规则和模型设置，可补充修改要求，再点击「创建并生成」。结果支持原图对比、仅看矢量结构、放弃、应用和撤销。PNG 原图刷新后重新选择。
- 「添加修改」旁的「添加文件」支持多选，也可将一批文件拖进编辑器。编辑器内拖入 PNG/SVG 均作为上下文，不替换画布；欢迎页拖入单个 PNG/SVG 可新建/打开项目。
- 文件最多 10 个，单个 10 MB、合计 20 MB；PDF 可指定页码，例如 `1-3,5`，所有 PDF 合计最多 20 页，全部附件提取文字合计最多 10 万字符。超限明确提示，不静默截断。
- PDF 提取文字并渲染页面，DOCX 提取文字及 PNG/JPEG/WebP 内嵌图片，DOC 提取文字，TXT/MD 等文本直接读取，PNG/JPG/WebP 作为视觉参考。其他二进制文件由本机 Codex 尝试读取，能否解析取决于本机工具；文件卡片明确显示已添加、已读取或读取失败，悬浮可查看完整原因。
- 图片附件旁的「按可编辑 SVG 重绘」默认关闭，开启后追加与 PNG 新建相同的规则，仍保持当前选区范围。附件在本次页面会话中按项目隔离，生成后继续保留，刷新后需重新添加。
- 生成和局部修改均显示「准备输入 → AI 生成 → 校验结果 → 预览确认」、耗时与等待动效，并可取消。阶段由服务端实际处理状态驱动，不显示虚构的模型完成百分比。
- 欢迎页「打开 SVG」或编辑器「导入 SVG」将文件作为独立项目打开，保留矢量元素、分组、变换、内部引用及常见 SVG 样式。
- 点击选择元素，Shift + 点击多选；左侧展开编组可访问子元素。
- 底部对话框始终显示：选中或框选一处，输入意见后点击「添加修改」或按 `Enter`，画布显示 1、2、3… 编号气泡，下方同步增加可删除的条目。`Shift+Enter` 换行，点击气泡或条目可定位原选区。
- 可累积多处意见后点击发送或 `Ctrl+Enter` 统一生成，逐条意见保留各自元素范围；预览可比较、应用或放弃。失败或放弃保留队列，应用后清空；条目与当前 SVG 草稿一起保存在浏览器，导入另一张 SVG 或新建画布会重置队列。编号气泡不会写入或导出到 SVG。
- `V` 选择与移动，`M` 矩形框选，`H` 或按住空格平移；滚轮缩放。
- 右侧调整填充、描边、线宽、透明度和文字；修改组颜色会应用到组内图形。
- 导出完整 SVG，或将选区剥离成独立 SVG，保留祖先变换与定义。
- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做。原有「导出 SVG」仍通过浏览器下载文件。
- 每个项目的画布、修改意见及磁盘文件关联自动保存在当前浏览器的 IndexedDB。刷新后通过历史项目打开；原图与附件不持久化，最终 SVG 中的局部内嵌素材随画布保存。磁盘文件仍需点击保存。

## Codex CLI

编辑器调用本机 `codex exec`，沿用本机模型配置与认证。先在终端安装并登录：

```powershell
npm install -g @openai/codex
codex login
```

如果 CLI 不在 PATH，可将 `CODEX_BIN` 指向 `codex.exe` 或 npm 安装的 `@openai/codex/bin/codex.js`。Windows 的 `.cmd`、`.ps1` 包装脚本不作为直接执行目标。

选择元素或框选区域 → 输入要求 → 点击发送（或 `Ctrl+Enter`）→ 对比预览 → 应用 / 放弃。修改支持撤销。状态栏“已检测到”仅表示找到 CLI，登录和模型可用性在实际请求中验证。

AI 输入框内可选择模型与思考强度，选择会保存在当前浏览器。模型选项及支持的强度来自本机 `$CODEX_HOME/models_cache.json`（默认 `~/.codex`），缓存不可用时仍可填写自定义模型 ID。缓存不是实时权限保证，最终以 CLI 请求结果为准。

默认跟随 CLI 配置，不改变本机配置文件；显式选择通过 `--model` 和 `-c model_reasoning_effort="…"` 传给本次请求。选择已知模型的「模型默认」会传递该模型缓存中提供的默认强度，避免继承其他模型不支持的档位。自定义模型的档位由 CLI 校验。参考 [OpenAI 配置文档](https://learn.chatgpt.com/docs/config-file/config-reference)。

AI 收到完整 SVG 作为上下文，以及允许修改的元素 ID 和框选坐标。完整 SVG 会发送给本机 Codex 配置的模型服务。服务器只接受选中根元素的替换；前端再次清理、验证元素结构和 ID，并生成可拒绝的预览。CLI 使用临时工作目录、只读沙箱、结构化输出，不使用绕过审批参数。SVG 上限 5 MB、300 个选中根元素，超时为 4 分钟，可取消。

文件解析在可取消的后台工作线程中运行，界面显示当前文件和页码；损坏、加密文件会明确报错，原有画布不受影响。所选页的文字和页面图像会发送给本机 Codex 配置的模型服务，需使用支持图片输入的模型。渲染图片保存在每次请求的临时目录，请求结束后清理。PDF 仅作为参考，不扩大普通修改的选区范围。

PNG 输入通过 CLI 的 `--image` 附件发送给配置的模型服务，需使用支持图片输入的模型。上限 5 MB、4000 万像素、单边 16000 像素；文字、框线、箭头、背景色块及主体图形要求原生 SVG 重绘。独立小图标和局部图片允许裁切保留，由服务端按模型返回的来源与坐标实际裁切，不接受模型自行嵌入整图。新增图片在目标画布中单块不超过 20%、累计不超过 40%，主 PNG 的裁切范围也遵循这两个上限；独立上传的小图标可以使用素材完整范围。目标面积按完整祖先变换计算；禁止通过 use、蒙版、pattern 或 CSS 几何变换铺底。预览「仅看矢量结构」可隐藏全部图片检查主体。AI 重建并非像素级无损转换，文字、连线和科学含义需要对照原图检查。应用生成结果会解除旧文件绑定，保存时选择新位置。

实现参考：[OpenAI 官方非交互模式文档](https://learn.chatgpt.com/docs/non-interactive-mode)。

## 支持范围

- 面向真实 SVG 矢量结构，不能把 SVG 中嵌入的位图自动还原成路径，也不能把已转曲文字还原为文本。
- 框选选择完整包含的元素；不会切断路径。编组可整体修改，也可展开编辑内部元素。
- 导入上限 5 MB。会移除脚本、动画、外部资源、链接和 `foreignObject`。常规 CSS 规则会限定在 SVG 内，媒体查询等复杂样式不保留。建议论文图片使用自包含的静态 SVG。
- 修改文字内容会合并该文字元素内的 `tspan`，原来的分段样式会消失；仅修改颜色、字体、字号则保留分段结构。
- 拆分编组通过每个子元素的独立包装组保留原始样式和变换；复杂滤镜、混合与组透明度效果应在导出前检查。
- 本地工具，仅监听 `127.0.0.1`，不适合直接部署为公共服务。

## 验证

```powershell
npx playwright install chromium
npm test
```

如果已有可用的 Chromium，可以避免重复下载：

```powershell
$env:PLAYWRIGHT_EXECUTABLE_PATH = 'C:\path\to\chrome.exe'
npm test
```

测试覆盖请求范围限制、本地接口访问限制、SVG 导入清理、CSS 隔离、选区导出、元素修改/移动/持久化、文本编辑、撤销重做和 AI 预览流程。新增 PNG 格式与尺寸校验、CLI 图片附件与阶段流、PNG 生成/对比/撤销/失败/放弃/取消覆盖。自动化 AI 界面测试使用模拟响应，不消耗模型请求。

共享重绘提示词在 `public/reconstruction.js`，前端规则说明与服务端生成共用。自动化还覆盖欢迎页、草稿迁移、项目隔离、混合文件拖入、图片重绘开关、受控素材裁切与铺底反例。仓库自带示例使用人工构造的测试图；本次发布的自动化 AI 验收使用测试替身，不代表真实模型质量评估。
